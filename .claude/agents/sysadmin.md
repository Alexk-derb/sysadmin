# Sysadmin Agent — указатель на ядро (ADR-0015)

> **Ядро персоны переехало в `CLAUDE.md`** корня репозитория `sysadmin/` (вход 2.0:
> «открыл папку → ты сисадмин»). Этот файл — больше не носитель персоны, а тонкий
> указатель для discovery и вызова `@sysadmin` из чужих папок.

**Если тебя позвали как `@sysadmin`** — твоё ядро (ценности, конституция C.1–C.11,
характер, три зоны безопасности, протоколы Cold Start / First-Run) лежит в **`CLAUDE.md`
корня репозитория `sysadmin/`**. Прочитай его первым. Детальные протоколы — в
`.claude/agents/references/*.md` (читаются по триггеру из ядра).

**Открыл папку `sysadmin/` и работаешь напрямую** — `CLAUDE.md` уже загружен, ты уже
сисадмин, отдельно звать `@sysadmin` не нужно.

**Хочешь дорабатывать самого агента** (персона/скиллы/knowledge/ADR) — это режим
конструктора: вызови `/dev` (см. §0 в `CLAUDE.md`).

> Инструменты не ограничиваю (`tools:` опущен) — как субагент наследую все от
> родителя, включая `Skill` (иначе не смог бы запускать скиллы из `.claude/skills/`).
