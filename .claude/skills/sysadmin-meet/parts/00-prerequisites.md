**Часть 0 (вводная). Что нужно иметь до старта — честный список**

Сразу по-честному, без убаюкивания: чтобы агент заработал, от тебя нужно несколько
базовых вещей. Их немного, но сделать вид, что «ничего не нужно знать», было бы обманом —
а обман не в моих правилах. Пробегись по списку, отметь, чего не хватает.

**1. Терминал и Claude Code.** Ты сейчас читаешь это внутри Claude Code — значит, главное
уже есть. Базовое умение «открыть терминал, перейти в папку, вставить строку и нажать
Enter» понадобится. Это не программирование — это как набрать адрес в браузере.

**2. git — чтобы скачать агента и потом обновлять.** Репозиторий агента ты получаешь через
`git clone`, а обновления (новые версии мозга) — через `git pull` / checkout по тегу.
Если слово «git» пугает — не страшно: нужно знать буквально две команды, я подскажу их по
ходу. Но совсем мимо git пройти не выйдет.

**3. Доступ к серверу по SSH (`~/.ssh/config`).** Это ключевое и часто пропускают.
**Агент работает на сервере ТВОИМИ руками — через твой SSH-доступ.** Если ты из терминала
не можешь зайти на сервер командой вида `ssh мой-сервер`, то и агент не сможет: у него нет
отдельного входа, он пользуется твоим. Практически это значит: у тебя есть SSH-ключ и в
файле `~/.ssh/config` прописан короткий алиас сервера (`Host мой-сервер` / `HostName <ip>` /
`User root` / `IdentityFile ~/.ssh/...`). Нет ключа или алиаса — это первое, что настроим
(или подскажу как).

**4. `jq` — маленькая утилита для конфигов.** Несколько скиллов (включая настройку
`/sysadmin-init`) читают/пишут JSON через `jq`. На macOS — `brew install jq`, на
Debian/Ubuntu — `sudo apt install jq`, на Windows (Git Bash) — `winget install jqlang.jq`.
`/sysadmin-init` это проверяет и подскажет, если `jq` нет. Без `jq` настройка
останавливается с понятным сообщением — не молча.

**5. Телеграм-бот (только если хочешь алерты).** Чтобы агент слал уведомления «сайт упал»
/ «бэкап старый» в Telegram, нужен бот: пишешь в Telegram пользователю **@BotFather**,
командой `/newbot` создаёшь бота, получаешь токен и имя. Это опционально — нужно только
для мониторинга и алертов бэкапа. Без алертов агент тоже работает.

---

**А если сервера ещё нет? Это нормально — учиться можно уже сейчас.**

Не обязательно иметь VPS, чтобы пройти знакомство и даже частично настроить агента:

- **«Сервера пока нет, просто разбираюсь»** — проходи это знакомство целиком, читай скиллы,
  разбирайся в словаре. Ничего на сервере не произойдёт — нечему. Когда купишь VPS
  (Selectel/Timeweb/Hetzner — от ~5$/мес), вернёшься к настройке.
- **«Сервер скоро будет»** — можно запустить `/sysadmin-init` и завести профиль (язык,
  менеджер паролей, имя проекта), а сервер вписать позже через `/sysadmin-init --reconfigure`.
  Скиллы, которым нужен живой сервер (`/bootstrap-new-server`, `/health-check`,
  `/inventory-scan`), подождут — они честно скажут «нет доступа к серверу», а не выдумают.
- **«Сервер уже есть и я в него захожу по SSH»** — отлично, ты готов ко всему. После
  знакомства иди на `/sysadmin-init`.

Не переживай, если по списку чего-то не хватает: ни один пункт не требует быть айтишником,
и на каждом шаге я объясняю, что и зачем. Главное — я не делаю вид, что этих вещей не
существует.
