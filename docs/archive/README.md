# docs/archive — исторические артефакты разработки

Здесь лежат **процессные** документы, которые сопровождали разработку агента, но не
являются частью продукта: отчёты аудитов, чек-планы релизов, отчёты сессий и внешние
рисёрчи. Они вынесены сюда из корня репозитория (этап 1 рефакторинга, 13.06.2026), чтобы
корень содержал только то, что нужно пользователю агента.

Эти файлы **заморожены** — на них ссылаются некоторые ADR в `decisions/` как на основание
принятых решений. Они не обновляются и не являются актуальной документацией.

| Файл | Что это |
|---|---|
| `AUDIT-2026-05-16.md` | отчёт аудита репозитория 16.05.2026 |
| `AUDIT-METHODOLOGY.md` | методология аудита скиллов по методичкам Anthropic (основание ADR-0001…0004) |
| `CHECK-PLAN.md` | чек-план подготовки релиза 1.0.0 |
| `REVIEW-2026-05-16-DONE.md` | закрытое ревью репозитория |
| `SESSION-VPN-2026-05-15.md` | отчёт VPN-сессии (основание ADR-0005) |
| `SESSION-VPN-LIVE-KNOWLEDGE-2026-05-17.md` | отчёт по live-слою VPN-знаний (основание ADR-0006) |
| `.planning/` | 4 внешних рисёрча по VPN/sing-box + release notes 1.0.0 (источник ADR-0005) |
| `REPORT-RULE-20260803.md` … `REPORT-RULE5-20260803.md` | пять кругов внешней сверки правила кросс-ревью за один день (основание ADR-0024, редакции 2–5). Круг 4 дал третий исход «безопасный результат не получен» — правило впервые применено к самому себе |

**Актуальная документация** — в корне репо (`README.md`, `CHANGELOG.md`, `UPGRADE.md`),
в `decisions/` (ADR) и в `.claude/` (персона, скиллы, знания).
